# Alibaba Daily Stats Exporter

这是一个 Chrome Manifest V3 插件，用于每天定时采集三个阿里巴巴国际站店铺页面上的询盘数和 TM 数，并默认写入 WPS 云文档在线表格。

## 能做什么

- 默认每天下午 5 点运行。
- 依次打开 3 个已配置的店铺数据页面。
- 可以通过“点哪个数字就选哪个数字”的方式自动生成 CSS 选择器。
- 按保存的 CSS 选择器读取“询盘数”和“TM 数”。
- 将采集结果写入 WPS 云文档在线表格，包含 3 个店铺和 1 行合计。
- 可选写入 WPS 后同时下载 CSV 备份。
- 支持点击插件弹窗里的“立即采集并写入 WPS”手动运行。

## WPS 写入说明

插件使用金山文档开放平台的在线表格接口写入数据：

- 接口主机：`https://developer.kdocs.cn`
- 写入接口：`POST /api/v1/openapi/ksheet/:file_token/sheets/:sheet_idx/cells`
- 写入方式：按单元格批量更新，字段顺序为 `日期、店铺、询盘数、TM数、来源页面、状态、采集时间`

你需要在设置页填写：

- WPS `access_token`；
- WPS 在线表格 `file_token`；
- sheet 序号；
- 起始行、起始列（都从 0 开始计数，例如 A2 是起始行 `1`、起始列 `0`）。

> 注意：`access_token` 需要由你的金山文档开放平台应用或授权流程提供。浏览器插件不能绕过 WPS/金山文档的开放平台鉴权，也不能在未授权的情况下直接写入任意云盘文件。

## 安装方式

1. 打开 Chrome：`chrome://extensions/`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录：`chrome-extension/alibaba-stats`。
5. 点击插件图标，进入“打开设置”。

## 配置方式

每个店铺需要填写：

- 店铺名称；
- 数据页面 URL。

选择询盘数/TM 数的方法：

1. 在设置页填好店铺数据页面 URL。
2. 点击“点选询盘数”或“点选 TM 数”。
3. 插件会打开该店铺数据页面，并在页面顶部显示提示。
4. 直接点击页面上你要统计的那个数字。
5. 插件会自动生成并保存 CSS 选择器。
6. 如果点错了，重新点击对应按钮再选一次即可；按 `Esc` 可以取消本次点选。

## 使用建议

- 第一次使用先点击“立即采集并写入 WPS”，确认选择器和 WPS 写入配置都正确。
- 如果弹窗提示缺少 WPS `access_token` 或 `file_token`，请先在设置页补齐。
- 如果 WPS 返回鉴权或权限错误，请检查开放平台应用授权、token 有效期、file_token 和文档写入权限。
- 如果 WPS 表格中状态显示“未匹配到选择器”，说明页面结构或选择器不正确。
- 如果后台登录过期，插件打开页面后可能只能读取到登录页，需要先手动登录对应账号。
- 如果页面加载慢，可把“页面加载后等待毫秒数”调大，例如 `15000`。
