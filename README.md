# Alibaba Daily Stats Exporter

这是一个 Chrome Manifest V3 插件，用于每天定时采集三个阿里巴巴国际站店铺页面上的询盘数和 TM 数，并下载本地 CSV 表格。

## 能做什么

- 默认每天下午 5 点运行。
- 依次打开 3 个已配置的店铺数据页面。
- 可以通过“点哪个数字就选哪个数字”的方式自动生成 CSS 选择器。
- 按保存的 CSS 选择器读取“询盘数”和“TM 数”。
- 生成包含 3 个店铺和 1 行合计的 CSV。
- 自动下载到 Chrome 默认下载目录。
- 支持点击插件弹窗里的“立即采集并下载 CSV”手动运行。

## 重要限制

Chrome 插件不能在未授权的情况下静默修改任意本地 Excel 文件，因此本插件采用浏览器允许的 `downloads` 能力，生成每日 CSV 文件。CSV 可以用 Excel、WPS、Numbers 打开，也可以后续再用脚本合并到固定总表。

如果必须直接写入固定本地 Excel 文件，需要增加 Native Messaging 本地助手程序，或者改用 Google Sheets / 飞书表格 API。

## 安装方式

1. 打开 Chrome：`chrome://extensions/`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录：`chrome-extension/alibaba-stats`。
5. 点击插件图标，进入“打开设置”。

## 配置方式

每个店铺需要填写：

- 店铺名称；
- 数据页面 URL。

选择询盘数/TM 数的方法：

1. 在设置页填好店铺数据页面 URL。
2. 点击“点选询盘数”或“点选 TM 数”。
3. 插件会打开该店铺数据页面，并在页面顶部显示提示。
4. 直接点击页面上你要统计的那个数字。
5. 插件会自动生成并保存 CSS 选择器。
6. 如果点错了，重新点击对应按钮再选一次即可；按 `Esc` 可以取消本次点选。

## 使用建议

- 第一次使用先点击“立即采集并下载 CSV”，确认选择器能正确读到数字。
- 如果 CSV 中状态显示“未匹配到选择器”，说明页面结构或选择器不正确。
- 如果后台登录过期，插件打开页面后可能只能读取到登录页，需要先手动登录对应账号。
- 如果页面加载慢，可把“页面加载后等待毫秒数”调大，例如 `15000`。
